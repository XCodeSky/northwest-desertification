# 模型说明

## 1. 模型基本信息

| 项目 | 内容 |
|---|---|
| 网站展示名称 | 西北荒漠化 1 km 多情景年度预测模型 |
| 推荐简称 | **NW-DESERT-1K v1.1** |
| 技术名称 | LightGBM–CA-Markov 多情景荒漠化等级预测模型 |
| 代码内部标识 | `lightgbm_1km_full` |
| 模型版本日期 | 2026-10-09 |
| 研究区域 | 新疆、甘肃、青海、宁夏、陕西 |
| 历史范围 | 2000—2025 |
| 预测范围 | 2026—2050 |
| 空间尺度 | 0.01°经纬度格网，名义约 1 km |
| 直接驱动情景 | SSP1-2.6、SSP2-4.5、SSP5-8.5 |
| 气候模式 | IITM-ESM |
| 输出等级 | 稳定、轻度、中度、重度、极重度 |
| 模型性质 | 研究型遥感代理与情景预测模型 |

本模型以 2000—2025 年土地覆盖、MODIS NDVI 和荒漠化代理等级变化为历史基础，使用 LightGBM 学习五年期格网状态转移规律，再通过 Markov 转移需求、15×15 格网邻域和 NEX-GDDP-CMIP6 气候压力完成空间分配。当前已经分别使用 SSP1-2.6、SSP2-4.5 和 SSP5-8.5 的真实降水、气温数据生成 2026—2050 年逐年产品。

三个情景**共享同一个历史训练模型和同一套参数**，不分别重新训练。情景间的差异来自各自的降水、气温和气候压力场对未来转移空间适宜度的修正。

## 2. 模型总体路径

```text
ESA CCI土地覆盖 + MODIS NDVI
                │
                ▼
      五级荒漠化代理标签
                │
                ▼
2000—2025年五个5年转移期样本
                │
                ▼
     LightGBM转移概率 P_ml
                │
       ┌────────┼────────┐
       ▼        ▼        ▼
 Markov需求  15×15邻域  CMIP6气候压力
       └────────┼────────┘
                ▼
       CA-Markov竞争分配
                │
                ▼
 2030/2035/2040/2045/2050锚点
                │
                ▼
 按格网转移适宜度分配到中间年份
                │
                ▼
等级 + 置信度 + 90%区间 + 面积 + 风险指数
```

完整实现包括：

1. 遥感数据获取、投影、重采样和缺失值修复。
2. 土地覆盖与 NDVI 阈值生成五级历史代理标签。
3. 构建五个历史转移期、11维特征的全量训练样本。
4. LightGBM 输出每个格网进入五个目标等级的概率。
5. 历史 Markov 矩阵决定五年周期内各等级的转移数量。
6. 邻域比例和情景气候压力修正格网转移适宜度。
7. CA 竞争分配确定转移发生的空间位置。
8. 将五年锚点变化分成五批，生成连续逐年产品。
9. 输出等级、置信度、90%等级区间、统计表和4K地图。

## 4. 历史数据与模型输入

### 4.1 土地覆盖

- 数据：ESA CCI Annual Global Land Cover。
- 原始分辨率：300 m。
- 使用年份：2000、2005、2010、2015、2020。
- 2025处理：沿用2020年土地覆盖。
- 重采样：众数聚合至0.01°格网。

ESA类别归并为九类：耕地、林地、灌丛、草地/稀疏植被、水体、冰雪、裸地、不透水面和湿地。

### 4.2 植被指数

- 数据：MODIS/Terra MOD13A1.061 NDVI。
- 原始分辨率：500 m，16天合成。
- 代表时相：选取最接近当年7月15日的合成影像。
- 使用年份：2000、2005、2010、2015、2020、2025。
- 处理：质量检查、拼接、重采样和研究区内部缺失值修复。

### 4.3 内部NoData修复

输入土地覆盖与NDVI在研究区内的孤立空洞采用最近有效格网填补，范围被限制在西北五省掩膜内。当前正式年度输出每年均有3,140,227个有效格网，研究区内部NoData为0。原始数据和修复过程保留审计记录。

## 5. 五级荒漠化代理标签

训练目标由土地覆盖和NDVI构造，不是官方地面调查标签。

| 土地覆盖 | NDVI条件 | 等级 |
|---|---:|---|
| 耕地 | NDVI ≥ 0.35 | 稳定 |
| 耕地 | 0.20 ≤ NDVI < 0.35 | 轻度 |
| 耕地 | NDVI < 0.20 | 中度 |
| 灌丛/草地 | NDVI ≥ 0.45 | 稳定 |
| 灌丛/草地 | 0.30 ≤ NDVI < 0.45 | 轻度 |
| 灌丛/草地 | 0.18 ≤ NDVI < 0.30 | 中度 |
| 灌丛/草地 | NDVI < 0.18 | 重度 |
| 裸地 | NDVI ≥ 0.25 | 中度 |
| 裸地 | 0.12 ≤ NDVI < 0.25 | 重度 |
| 裸地 | NDVI < 0.12 | 极重度 |

其他有效土地覆盖默认归入稳定。该规则透明且可复算，但天然裸地和极低NDVI地区容易获得较高等级，因此网站必须使用“荒漠化代理等级”或“荒漠化风险等级”，不能表述为官方调查等级。

## 6. LightGBM 转移模型

### 6.1 输入特征

每个格网使用11项特征：

| 序号 | 特征 | 含义 |
|---:|---|---|
| 1 | `current_class` | 当前五级代理等级 |
| 2 | `ndvi` | 当前NDVI |
| 3 | `ndvi_5y_trend` | 五年NDVI年均变化，截断至[-0.04, 0.04] |
| 4 | `land_cover` | 九类土地覆盖编码 |
| 5 | `longitude` | 格网中心经度 |
| 6 | `latitude` | 格网中心纬度 |
| 7 | `neighbor_non` | 邻域稳定比例 |
| 8 | `neighbor_light` | 邻域轻度比例 |
| 9 | `neighbor_moderate` | 邻域中度比例 |
| 10 | `neighbor_severe` | 邻域重度比例 |
| 11 | `neighbor_extreme` | 邻域极重度比例 |

NDVI趋势公式：

```text
ndvi_5y_trend = clip((NDVI当前锚点 - NDVI上一锚点) / 5, -0.04, 0.04)
```

### 6.2 邻域配置

- 窗口：15×15个1 km格网。
- 名义影响范围：约15 km × 15 km。
- 计算：窗口中五个等级各自占有效格网的比例。
- 研究区外格网不参与分母。

早期5 km原型采用3×3邻域；1 km正式版本采用15×15邻域以大致保持相同物理影响范围。网站不得继续把当前模型写成3×3邻域。

### 6.3 训练样本

| 转移期 | 样本数 |
|---|---:|
| 2000→2005 | 3,140,227 |
| 2005→2010 | 3,140,227 |
| 2010→2015 | 3,140,227 |
| 2015→2020 | 3,140,227 |

| 最终训练合计 | **15,701,135** |

训练特征以`float32`内存映射文件保存，目标类别以`uint8`保存。

### 6.4 时序验证

- 训练集：2000→2005至2015→2020，共12,560,908条样本。
- 留出集：完整2020→2025，共3,140,227条样本。
- 验证模型：420棵树。
- 最终模型：使用全部五个转移期重训，520棵树。

| Accuracy | 88.60% |
| Balanced Accuracy | 81.77% |
| Macro-F1 | 81.88% |

这是时间留出验证，比随机拆分更接近未来外推条件。但指标衡量的是对遥感代理标签的复现能力，不等于对官方地面调查等级达到相同精度。

## 7. Markov 转移矩阵

五个历史转移期用于统计5×5经验转移矩阵：

- 初始计数全部加1，进行Laplace平滑。
- 2000→2005、2005→2010、2010→2015权重为1。
- 2015→2020、2020→2025权重为2。
- 按当前等级逐行归一化。

| 当前等级 \ 目标等级 | 稳定 | 轻度 | 中度 | 重度 | 极重度 |
|---|---:|---:|---:|---:|---:|
| 稳定 | 93.9367% | 5.8010% | 0.2406% | 0.0157% | 0.0059% |
| 轻度 | 26.2577% | 57.5590% | 15.7654% | 0.4178% | 0.0001% |
| 中度 | 1.7083% | 19.5597% | 63.3116% | 15.3648% | 0.0556% |
| 重度 | 0.2198% | 0.4895% | 10.8547% | 82.4384% | 5.9977% |
| 极重度 | 0.0264% | 0.0033% | 0.0872% | 3.9033% | 95.9798% |

Markov矩阵控制一个五年周期内每类格网的目标转移数量；LightGBM、邻域和气候压力决定这些转移发生的位置。

## 8. CA-Markov 概率融合

### 8.1 基础融合

```text
P_base = 0.62 × P_LightGBM + 0.38 × P_Markov
```

### 8.2 邻域修正

```text
P_neighbor = P_base × (0.70 + 0.30 × 目标等级邻域比例)
```

### 8.3 气候修正

```text
P_final = P_neighbor × exp(0.08 × 气候压力 × 等级严重度轴)
等级严重度轴 = [-2, -1, 0, 1, 2]
```

所有类别概率最后重新归一化。

### 8.4 竞争分配

1. 根据Markov矩阵计算每个起始等级需要转向其他等级的格网数。
2. 计算`P_final(目标等级) / P_final(保持原等级)`。
3. 优先选择比值最高的格网完成转移。
4. 已分配格网不再参与同一五年周期内的其他转移。
5. 其余格网保持原等级。

在输入、软件版本和随机种子相同的条件下，结果可复现。

## 10. 气候压力计算

每个情景分别以自身2025年为基线：

```text
温度异常 = tas_year - tas_2025
降水变化率 = (pr_year - pr_2025) / max(pr_2025, 50 mm)
气候压力 = clip(温度异常 / 3 - 降水变化率 / 0.50, -1, 1)
```

正值提高较严重等级的相对适宜度，负值提高较轻等级的相对适宜度。系数0.08被刻意设置为弱修正，使粗尺度单一气候模式不会压过历史遥感转移和邻域结构。

## 11. 未来NDVI与土地覆盖

### 11.1 NDVI外推

```text
长期趋势 = clip((NDVI_2025 - NDVI_2015) / 10, -0.012, 0.012)
下一锚点NDVI = clip(当前NDVI + 5 × 长期趋势, -0.1, 0.95)
```

三个情景使用相同NDVI长期趋势，因此情景差异只来自气候压力，不来自单独的植被响应模型。

### 11.2 土地覆盖

预测期固定使用2020年土地覆盖，不显式模拟未来城市扩张、耕地调整、退耕还林、光伏建设或防护林工程造成的土地覆盖改变。

## 12. 五年锚点年度化

模型学习的是五年转移，不能每年重复运行，否则会造成转移过量。年度化方法如下：

1. 先计算2030、2035、2040、2045、2050完整五年锚点。
2. 找出每个五年区间中起点和终点等级不同的格网。
3. 按目标等级相对于原等级的适宜度从高到低排序。
4. 把待转移格网近似等分为五批。
5. 适宜度最高的一批在第1年变化，其余依次在第2—5年变化。

年度概率公式：

```text
alpha = 五年区间内步数 / 5
P_year = alpha × P_anchor
P_year(起始等级) += 1 - alpha
```

年份状态包括：

- `historical_anchor`：历史代理观测锚点。
- `historical_interpolation`：历史锚点间年度化。
- `forecast_anchor`：完整五年预测锚点。
- `forecast_annualized`：预测锚点间年度化。

## 13. 置信度与90%预测区间

### 13.1 像元置信度

```text
confidence = P_year(最终CA分配等级)
```

置信度表示模型概率对最终分配类别的相对支持，不是现实世界中“预测正确的概率”。历史代理锚点置信度设为1.0，仅表示代理输入完整，不代表官方调查准确率为100%。

### 13.2 90%等级区间

先根据五个有序类别的累计概率取得5%和95%分位等级。由于CA-Markov的全局数量约束可能选择并非单格网MAP的类别，最终区间采用：

```text
最终下限 = min(中央90%下限, CA点预测等级)
最终上限 = max(中央90%上限, CA点预测等级)
```

因此所有年度和情景均满足：

```text
下限 ≤ 点预测等级 ≤ 上限
```

原始中央区间保存在各目录的`raw_central_interval_backup/`。修复审计文件为：

`outputs/model_1km_full/scenarios/interval_envelope_repair_report.json`

受影响的“格网×年份”比例：

| 情景 | 调整比例 |
|---|---:|
| SSP1-2.6 | 0.1618% |
| SSP2-4.5 | 0.1037% |
| SSP5-8.5 | 0.1598% |

### 15.1 为什么总面积差异较小

- 全区类别总量相近。
- 不同纬度格网面积不同，因此面积仍会出现小幅差别。
- 情景影响主要表现为空间位置差异，而不是全区总量剧烈分离。

## 16. 综合风险指数与面积校准

该部分是空间预测之后的统计层，不参与LightGBM训练。

### 16.1 土地风险指数

```text
land_risk = 按像元实际面积加权平均(class / 4)
```

### 16.2 SSP2-4.5既有综合风险指数

现有省级综合风险表使用：

```text
降水亏缺风险 = clip(-相对2025年降水异常百分比 / 20, 0, 1)
增温风险 = clip(相对2025年气温异常 / 3, 0, 1)
综合风险 = clip(
    0.65 × 土地风险
  + 0.20 × 降水亏缺风险
  + 0.15 × 增温风险,
  0, 1
)
```

SSP1-2.6和SSP5-8.5已完成空间栅格预测，但现有县区旧版情景表仍是此前的参数化对照版本。在重新按新栅格汇总前，网站不得把旧县区表标为三套直接气候驱动结果。

### 16.3 面积校准

- 等级≥1计入荒漠化代理面积。
- 等级≥3计入重度及以上面积。
- 省级正式展示表可使用2019公开面积锚点进行比例校准。
- 校准因子：`2019官方面积 / 2019模型面积`。
- 同一省份各年份使用同一校准因子。

## 19. 主要假设与限制

1. **代理标签**：历史等级由土地覆盖和NDVI规则生成，不是官方调查真值。
2. **天然裸地偏向**：天然裸地和极低NDVI地区容易被划为重度或极重度。
3. **单气候模式**：三个情景均使用IITM-ESM，不是多模式集合。
4. **气候插值**：0.25°插值到0.01°不会增加真实气候分辨率。
5. **土地覆盖固定**：未来土地覆盖固定为2020年状态。
6. **NDVI线性外推**：不表达突发干旱、火灾和重大生态工程。
7. **共享植被路径**：三个情景没有独立的气候—植被响应模块。
8. **Markov数量约束**：情景主要改变转移位置，限制了全区总量对气候情景的敏感度。
9. **转移稳定性**：假设历史转移结构可以延续至未来。
10. **缺少显式人类活动情景**：未直接模拟地下水开采、放牧、耕地扩张、生态补水和政策冲击。
11. **空间自相关**：数百万像元并非相互独立的观测样本。
12. **验证范围**：当前主要为单一2020→2025时序留出，尚缺滚动时间验证、留省验证和官方样点外部验证。
13. **概率未外部校准**：置信度不能直接解释为现实正确率。
14. **县区旧表**：旧版县区多情景表尚未按新栅格重算。

## 20. 网站推荐文案

### 20.1 模型摘要

> NW-DESERT-1K v1.1采用1 km LightGBM–CA-Markov方法，融合土地覆盖、MODIS NDVI、历史等级转移、15×15邻域状态以及SSP1-2.6、SSP2-4.5和SSP5-8.5气候压力，生成西北五省2000—2050年五级荒漠化风险产品。模型在2020→2025独立时序留出集上的Macro-F1为81.88%，Cohen's Kappa为0.8464。历史等级为遥感代理标签，未来结果为研究型情景预测。

### 20.2 参数摘要

> LightGBM五分类，520棵树，学习率0.055，64叶，最小叶节点样本200，L2正则1.2；机器学习与Markov权重0.62/0.38，15×15邻域影响权重0.30，气候修正系数0.08，随机种子42。三个情景均采用IITM-ESM NEX-GDDP-CMIP6数据。

### 20.3 情景说明

> 三个情景共享同一历史训练模型，只替换对应情景的降水、气温和气候压力。由于Markov转移数量约束，情景差异主要体现在风险迁移的空间位置，而不是西北五省总面积的剧烈变化。

### 20.4 免责声明

> 本模型服务于科研、教学和决策辅助。结果受遥感误差、代理标签、单一气候模式、土地覆盖固定、NDVI外推和历史转移稳定性假设影响，不能替代国家荒漠化调查、标准地图或现场勘查结论。
